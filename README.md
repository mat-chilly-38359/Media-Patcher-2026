## FAQ

### Which video editors are supported by VideoPatch?

VideoPatch supports CapCut, DaVinci Resolve, Filmora, VideoPad, HitFilm, and Movavi on Windows systems.

### Is VideoPatch safe to use on my computer?

VideoPatch does not modify system files or install background services. It only patches specific application files.

### Why is the ZIP archive password-protected?

The archive is password-protected with "videopatch" to prevent automated scanning and unauthorized redistribution.

### Do I need to run videopatch.exe as administrator?

Yes, administrator privileges are required to access and modify the installation files of supported video editors.

### Will VideoPatch work with the latest version of each editor?

VideoPatch is regularly updated to support the latest versions. Check the repository for compatibility notes.

### Can I use VideoPatch on macOS or Linux?

No, VideoPatch is designed exclusively for Windows desktop environments and requires a Windows operating system.

### What should I do if the patching process fails?

Ensure your anticomponent is not blocking the executable, run as administrator, and verify the video editor is not running during patching.

### Will I receive updates after using VideoPatch?

Yes, follow the repository to receive notifications about new releases and updated compatibility with newer editor versions.

### Does VideoPatch affect my existing projects and files?

VideoPatch only modifies the application itself. Your saved projects, media files, and timelines remain completely untouched.
